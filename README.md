# ClassGPT-Documentation

Repositorio destinado a la documentacion, seguimiento y evolucion del proyecto **ClassGPT**.

Aqui se recoge la informacion que complementa al repositorio principal de codigo:

- Arquitectura y design del sistema.
- Seguimiento de los sprints.
- Revisiones y resultados.
- Problemas encontrados y soluciones.
- Decisiones tecnicas.
- Investigacion y comparativas.
- Material para entrega del TFG.

## Repositorios

- **ClassGPT-Code**: codigo fuente y configuracion del proyecto.
- **ClassGPT-Documentation**: documentacion y seguimiento del proyecto.
